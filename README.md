📌 Project Overview  

AtliQ Hardware sells computers and accessories through three primary channels:

- 🏬 Retailers  
- 🛒 Direct Sales  
- 📦 Distributors  

The company faced financial losses from a poorly planned store expansion in the USA. The expansion decision was based mainly on surveys and Excel-based analysis without a centralized analytics framework.

This exposed major challenges:

- Fragmented reporting across departments  
- Heavy dependency on multiple Excel files  
- Conflicting KPI definitions  
- Delayed visibility into declining sales  
- No structured marketing ROI tracking  
- Poor forecast accuracy monitoring  

Leadership required a centralized analytics solution to reduce guesswork and improve strategic decisions.

---

🎯 Objective  

Build a scalable BI solution that:

- Eliminates manual Excel consolidation  
- Standardizes KPIs across Sales, Finance, Marketing, and Supply Chain  
- Provides real-time performance visibility  
- Enables confident, data-backed expansion planning  

---

🛠️ Tech Stack  

- **MySQL** – Data extraction  
- **Power BI** – Data modeling & visualization  
- **Power Query (M Language)** – Data cleaning & transformations  
- **DAX** – KPI & business logic creation  
- **DAX Studio** – Performance optimization  
- **Excel** – Data validation & reconciliation  

---

⚙️ Solution Architecture  

 🔹 Data Layer  

- Extracted structured transactional data using MySQL  
- Performed full data transformation in Power Query  
- Created a custom Date Table using M language  
- Applied validation checks to ensure revenue and margin accuracy  

---
 🔹 Data Modeling  

- Designed a scalable **Snowflake schema**  
- Built optimized relationships between fact and dimension tables  
- Ensured efficient filter propagation and performance

  

---
 🔹 KPI Framework  

Developed standardized business KPIs:

- Net Sales  
- Revenue Growth (MoM, YTD)  
- Gross Margin %  
- P&L by customer, product, and region  
- Marketing ROI  
- Forecast Accuracy %  
- Net Error & Risk segmentation  

Optimized DAX measures using DAX Studio.
